# @aether/core

Platform-neutral workflow and engineering primitives for Aether.

This package provides workflow validation and planning, file-backed run state, run lifecycle and recovery, task delegation contracts, and evidence verification.

It does not launch platform agents. Agent execution is delegated to native host capabilities through `@aether/adapters` or human-mediated handoff.

See the [Aether repository](https://github.com/ifaamrillah/aether) for architecture, usage, and security constraints.
